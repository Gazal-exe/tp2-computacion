# Trabajo Práctico N° 2 - Computación II
## Unidad 3: Evaluación de Complejidad y Optimización

Este repositorio contiene el desarrollo y análisis del Trabajo Práctico N° 2 de la cátedra de **Computación II**.

### Contenidos del Repositorio
- `consignas.md`: Enunciado completo y consignas del trabajo práctico.
- `informe.md`: Informe detallado con análisis de complejidad, cuellos de botella y optimizaciones.
- Scripts de código fuente para cada punto del trabajo práctico (análisis empírico, profiling y optimizaciones).

### Objetivos
- Analizar la complejidad de diversos algoritmos (teórico y empírico).
- Identificar cuellos de botella en el código utilizando herramientas de perfilado (`cProfile`).
- Diseñar, fundamentar e implementar optimizaciones para mejorar el rendimiento temporal y espacial.
